# Assignment 1: What Happens Between Typing a URL and Seeing the Page?

1. The user types a URL into the browser and presses Enter.
2. The browser checks its cache for previously stored resources.
3. DNS converts the domain name into an IP address.
4. The browser connects to the server using the IP address.
5. The browser sends an HTTP request to retrieve the webpage.
6. If the website uses HTTPS, the connection is encrypted.
7. The server sends a response containing the webpage's HTML code.
8. The browser reads and parses the HTML.
9. The browser loads other required resources, such as CSS, JavaScript, and images.
10. Finally, the browser renders and displays the webpage on the screen.
