# Steps to Create a New Repository on GitHub

1. Open [GitHub](https://github.com) and log in to your account.

2. Click the **+ icon** in the top-right corner and select **New repository**.

3. Enter a repository name, such as `my-first-project`. You can also add a description if required.

4. Choose **Public** or **Private**, depending on your preference.

5. Select the **Add a README file** option if you want to create a README file.

6. Click the green **Create repository** button. Your new repository will be created successfully.

7. Create a folder on your computer and open it in Visual Studio Code (VS Code).

8. Open the terminal in VS Code and copy and paste the required Git commands to connect your local folder to the GitHub repository. Press **Enter** to execute each command.

9. After executing the commands successfully, refresh your GitHub repository page to verify that your files have been uploaded.
