Steps for creating new repo on github are as follows:
1.Open [GitHub](https://github.com) and log in to your account.
2.Click on the *+ icon* in the top-right corner and select New repository.
3.Enter your repository name, such as my-first-project, and add a description if required.
4.Choose Public or Private according to your preference.
5.Tick the Add a README file option if you want to create a README file.
6.Click on the green Create repository button. Your new repository is now ready then make a folder and add open it in vs code. 
7.Then copy a command and paste it on terminal then enter now refresh github the repo is ready.
